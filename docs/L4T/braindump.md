# get board parameters

```
sudo ./flash.sh --no-flash --no-systemimg jetson-orin-nano-devkit-super internal
```

This generates on STDOUT/ERR the values for
 * BOARDID
 * BOARDSKU
 * BOARDREV
 * FAB
 * RAMCODE

Those are partially documented in `./tools/kernel_flash/README_initrd_flash.txt`

For a Jetson Orin NX on standard NVidia carrier board this is:
 * BOARDID=3767
 * BOARDSKU=0000
 * FAB=301

These parameters depend on the SoC/board revisions.
 * RAMCODE=1
 * BOARDREV=G.1

With the following commands you genete image for later flashing for that hardware
```
sudo BOARDID=3767 BOARDSKU=0000 FAB=301 RAMCODE=1 BOARDREV=G.1 ./l4t_initrd_flash.sh --no-flash --erase-all jetson-orin-nano-devkit-super internal
```

Flashing commands are in `./bootloader/flashcmd.txt`.

`./tools/kernel_flash/images/internal/qspi_bootblob_ver.txt` contain even more board information.
This directory containers also the QSPI fimware blobs.

`./tools/kernel_flash/images/external` contains the files for the disk flashes.


# boot scheme

On the EFI system partition (ESP) is a file `/boot/efi/EFI/BOOT/BOOTAA64.efi`

This searches for EFI partition named:
 * `APP` for boot files.
 * `recovery`, `recovery-dtb` is used for recovery booting
 * `esp` is the EFI System partition

Unused/unknonw use for now
 * `A_kernel`, `A_kernel-dtb`, `A_reserved_on_user`
 * `B_kernel`, `B_kernel-dtb`, `B_reserved_on_user`
 * `recovery_alt`, `recovery-dtb_alt`
 * `esp_alt`
 * `UDA`
 * `reserved`

## typical extlinux.conf

for OrinNX Ext Super
```
LABEL primary
      MENU LABEL primary kernel
      LINUX /boot/Image
      INITRD /boot/initrd
      APPEND ${cbootargs} root=PARTUUID=x...x rw rootwait mminit_loglevel=4 console=ttyTCU0,115200 firmware_class.path=/etc/firmware fbcon=map:0 video=efifb:off console=tty0 efi_pstore.pstore_disable=1 pstore.backend=ramoops efi=runtime pci=pcie_bus_perf nvme.use_threaded_interrupts=1 swiotlb=2048
      #FTD  
```

## contents of `/etc/nv_boot_control.conf`
```
TNSPEC 3767-301-0000-G.1-1-0-jetson-orin-nano-devkit-super-
COMPATIBLE_SPEC 3767-000-0000--1--jetson-orin-nano-devkit-super-
TEGRA_CHIPID 0x23
TEGRA_OTA_BOOT_DEVICE /dev/mtdblock0
TEGRA_OTA_GPT_DEVICE /dev/mtdblock0
```

This file can be generated by an flashing attempt.
